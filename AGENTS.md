# Implementation scope

`Godot/archive/d1_demo/` (the old demo folder) consists of AI slop retained as an archived deliverable. It MUST NOT be counted as real implementation, working functionality, or evidence that a feature exists in the current Schola Godot plugin.

Exclude that folder when assessing implemented features or answering questions about available nodes, UI bindings, APIs, and runtime behavior. Do not reuse its code unless the user explicitly asks to work on the archived demo.

Legacy C# files also remain under `Godot/addons/schola/`, including `ui/RewardStatusPanel.cs` and `nodes/`. Their presence alone does not establish current functionality. Verify features against the active C++ GDExtension registrations, build configuration, and current scenes before claiming they are available.
